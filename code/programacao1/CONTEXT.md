# programacao1
> Simulador de sociedade em Python puro. Duas camadas: (1) terminal CRUD de pessoas (missões 0–6 concluídas); (2) simulador social com mercado, decisão, empreendedorismo — em desenvolvimento.
> goal: none

Constraints: só funções, loops, condicionais, listas, dicionários. Sem classes. Sem libs externas.

Quick-start: `python main.py` (requer `rsc/pessoas_pequeno.csv`).

Ver `SPECS.md` para arquitetura completa do simulador.
