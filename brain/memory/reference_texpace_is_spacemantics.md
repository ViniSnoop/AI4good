"texpace" = the spatial+temporal DSL that is the core of the **spacemantics** project (`code/spacemantics/`, goal
`brain/goals/spacemantics.md`). When Lucas names texpace in a capture, route it to spacemantics (e.g.
`code/spacemantics/refs/REFS.md`), including sub-DSL / UI-DSL ideas layered over texpace. See [[project_spacemantics]].
